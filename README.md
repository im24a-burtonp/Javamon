I made this project during a Java class for school. We had to make a project with the entire backend being in Java. I had never used Java before, so it was good practice to learn a language I had never used before. 

We would regularly have one-on-one discussions with the teacher, where we had to show him where we stood and even some parts of the code. 

Understanding the code was a big part of the class. I made sure to achieve this by never running AI in agent mode. I always tried something out myself, then asked the AI for better ways of accomplishing the same thing or for a solution if i was ever stuck. I learned quite a lot and actually understood the code I was writing.

At the end of the class we had to present the project along with how it works. My classmates really enjoyed my project. Feel free to run it yourself!
