I created this project for a Java class where the entire backend had to be written in Java. Since I had never used Java before, it was a valuable opportunity to learn a new language through a practical project.

Throughout the course, we regularly met one-on-one with our teacher to demonstrate our progress and explain parts of our code. Because understanding the implementation was an important part of the class, I made a conscious effort to understand and write the code myself. I used AI as a learning tool: I first tried to solve problems independently, then used it to compare approaches, improve my solutions, or get unstuck.

This process helped me build confidence with Java and develop a deeper understanding of the code I was writing.

At the end of the course, I presented the project and explained how it worked. My classmates responded positively, and the presentation was a rewarding way to finish the project.

Feel free to explore the code.

## What I Learned

- Java fundamentals and object-oriented programming
- Structuring a backend application
- Debugging and explaining code
- Presenting technical decisions clearly
